Files for a project, I'm currently working on.
The aim is to create a set of templates that can easily be adapted to the display of new data.
It has two parts:
- part one: overlay an image, normally some geographical map, with a grid and catch the clicks on cells of the grid. This way, you can mark interesting points on the map and get their griss coordinates.
- part two: highlight the marked grid coordinates, with or without underlying map, and catch clicks in order to display tooltips or whatever.
